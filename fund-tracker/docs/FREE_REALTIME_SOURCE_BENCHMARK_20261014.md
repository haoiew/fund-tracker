# 免费基金估值源：稳定性、速度与备用源评估

采样日：**2026-10-14，Asia/Shanghai**。本报告的采样阶段只评估，不改变生产配置。**后续用户已批准新浪优先及 Dayfund/Fund123 接入，并要求全源并发、返回即显示；当前实现与验收见[实时估值运行策略](ESTIMATE_FALLBACK_20261014.md)。** 下列时延和覆盖保留为采样时证据。

## 决策结论

1. **有另外两个免费可读的估值候选：基金速查 Dayfund、蚂蚁 Fund123。** 两者均实际返回白酒、医药、先进制造的当日估值；并非只有估值入口或历史净值。但它们不是本次样本的全覆盖替代源。
2. **就本机当前网络、目标样本的访问速度和覆盖而言，新浪表现最佳。** 同条件六基金测试 P50 约 **14 ms**、覆盖 **6/6**；30 个广样本的 30 轮测试中始终有 **29 个有效当日估值**，剩余货币基金不按普通 NAV 计价。该结论不是准确度排名。
3. **天天的主要风险不只是不覆盖主动基金，还有“能快速响应但估值陈旧”。** 14:58–15:03 的 30 轮均 HTTP 200，但原本有 GSZ 的 5 只报价停在 14:37–14:39，均超过项目 15 分钟时效阈值；15:05 复查已恢复。不能用网络成功率 100% 掩盖这一段有效估值缺口。
4. **采样后的接入决定已由用户作出：新浪 → 天天 POST → Dayfund → Fund123 → 本地推算。** 全源并发请求，首页按优先级渐进选价；天天 GET/POST 不重复登记。这里的性能比较不是未经授权自动接入的依据。

证据：[30 轮广样本](../../data-source-test/reports/stability_samples_20261014.json)、[同条件五条路径比较](../../data-source-test/reports/realtime_benchmark_20261014.json)、[其他公开路径检查](../../data-source-test/reports/other_free_candidates_20261014.json)。

## 先分清评估对象

- **源端估值**：平台计算并提供的基金估算价格，人民币份额一般为元/份，不是基金公司正式公布的单位净值。
- **请求成功率**：HTTP 200 的请求比例；还要另查业务结构、是否有估值和时间是否有效。HTTP 200、业务 success、旧正式 NAV 均不能单独证明实时估值可用。
- **可用估值覆盖**：在指定样本中满足当前项目报价规则的代码数量。本次收盘后包含当日最后估值，不表示全部基金/底层市场仍在交易或报价持续推进。
- **P50/P95 延迟**：本机每轮取得整批样本的耗时，中位数/95% 分位数，单位 ms。P95 用线性插值，含首轮连接建立；小样本 P95 不是长期性能保证。
- **实际报价年龄**：获取时刻减去来源行情时刻，单位秒；未按上海收盘钳制，保存在 JSON 中，含已拒绝的陈旧估值。例如 Dayfund 标普500的 09:15 会使最大年龄接近六小时，但它没有被计为可用报价。

## 一、同条件速度与覆盖

**15:14:51–15:17:08，10 轮，轮间等待 15 秒。** 固定六只：`012414` 白酒 C、`015916` 医药 C、`018125` 先进制造 C、`016531` 碳中和 C、`012349` 恒生科技联接 C、`017641` 标普500 QDII A。

各源绕过本应用缓存直接取数，Session 复用；单代码源每批最多并发 2 个请求，不加自动重试。不支持批量的来源确实发出六次请求，不拿“查一只的速度”与“查六只的速度”混比。

| 来源/路径 | HTTP 成功 | 整批六只 P50 | 整批六只 P95 | 每轮可用估值 | 主要判断 |
|---|---:|---:|---:|---:|---|
| 新浪 `fu_` 批量 | 10/10 | **14.00 ms** | **32.07 ms** | **6/6** | 本轮最快、覆盖最完整 |
| 天天 H5 GET（采样时生产方式，现已移除） | 10/10 | 43.15 ms | 223.18 ms | 2/6 | 白酒、恒生科技有估值，其余为正式 NAV |
| 天天 H5 POST（官方 H5 方式） | 10/10 | 46.00 ms | 86.37 ms | 2/6 | 同一服务的请求方式，不是新供应商 |
| **Dayfund 候选**，六次 GET | 60/60 | **76.02 ms** | 324.62 ms | **5/6*** | 接入较轻，但跨境报价陈旧 |
| **Fund123 候选**，六次 POST | 60/60 | **223.99 ms** | 233.41 ms | **4/6** | 国内四只可读，两只跨境样本无分时点 |

**网络条件限制：**本次请求继承已有 HTTP/HTTPS 代理 `127.0.0.1:10808`，没有修改代理或关闭 TLS 校验。延迟包含这一网络路径及可能的上游/CDN 缓存，不能推广为全国直连速度排名。第一轮 Dayfund 为 520.26 ms，GET 有一轮 310.7 ms，少量尾部值显著影响小样本 P95。

**Fund123 冷启动须另加成本：**六个匿名档案页面初始化共 **623.88 ms**，用于取得正常页面提供的产品 ID/CSRF；首批估值另 **225.07 ms**，合计约 **849 ms**。后续 224 ms 的整批中位数不包含重复初始化。没有注册/登录或使用付费凭证，报告不保存 CSRF/Cookie。

\* **Dayfund 的 5/6 只代表项目当前显示规则下的当日参考可用，不是严格跨市场实时覆盖。** 本轮恒生科技时间为 **14:50**、标普500为 **09:15**；后者已被时效校核排除，前者在仍交易市场也明显偏旧。上海收盘后的通用钳制不足以证明港股/海外报价新鲜；不建议把 Dayfund 直接视作通用高频估值源。

## 二、稳定性：没有超时，不等于没有退化

### 30 轮、30 广样本，覆盖收盘前后

时间 **14:58:06–15:02:58**，每轮等待 10 秒。样本含原基准基金及医药/制造 A/C 等，`000198` 为货币基金负对照，因此普通基金分母为 29。使用生产解析器和 900 秒时效阈值。

| 指标 | 天天 H5 GET | 新浪批量 |
|---|---:|---:|
| HTTP 200 | 30/30 | 30/30 |
| 网络/解析异常轮数 | 0 | 0 |
| 整批 P50 / P95 | 45.70 / 55.01 ms | 14.95 / 25.27 ms |
| 原始响应提供估值的普通基金 | 5/29 | 29/29 |
| 通过当时项目时效校核的估值 | **0/29，每轮如此** | **29/29，每轮如此** |
| 解释 | 5 只有值但时刻停留在14:37–14:39，其余本就没有 GSZ | 存在有效当日报价，部分时间戳继续推进 |

后续 15:05 同批复核，天天 GET、POST 和普通 GET 加 `Cache-Control: no-cache` 均取得恢复后的 15:00/15:05 时刻。因此已确认的是**曾出现陈旧窗口、之后恢复**，不是 GET 一定失效或整个服务永久停供。

本次缺少当时直连/代理、缓存头及上游内部状态的同步对照，**无法进一步认定是哪一层缓存或上游更新造成**。官方 H5 确实使用 POST，但仅凭后续 POST 的较低 P95，不能宣称更换请求方式已经解决陈旧窗口。[官方 H5 请求脚本](https://h5.1234567.com.cn/app/fund-details/js/chunk-common.95006af8.js)。

### 候选源收盘后复读

十轮中各来源 HTTP、业务结构均未失败；没有发现“同一来源、同一代码、同一行情时刻却返回不同价格”的样本。新浪六只时间戳均有推进，天天恒生科技有推进；Dayfund 和 Fund123 本轮报价时刻没有推进。

**后两者在上海收盘后停止推进不能直接算故障**，但也不能据此证明盘中更新连续。Fund123 返回的国内四只当日序列各有 242 点、最后时刻为 15:00；Dayfund 两个跨境样本的陈旧/缺失问题则需要单独处理。跨市场交易日、时区、汇率和底层行情的真实时刻仍需更严格验证。

这只是短窗口测试，不足以估计月可用率、繁忙时段限流或 99.9% SLA；本轮没有据此生成虚假的“稳定性高分”。

## 三、新发现的免费备用源如何取数

### Dayfund：建议优先评估的第三备用

实际路径是 `GET /ajs/ajaxdata.shtml?showtype=getfundvalue&fundcode=代码`，而不是静态 HTML 的空白估值位置。其[自身 common.js](https://fund.dayfund.com.cn/templetes/qtx/js/common.js?v1)明确将管道分隔字段 **7** 显示为估值、**5** 显示为涨跌百分比、**9+10** 显示为行情日期/时刻；**1、0** 是正式单位净值及日期。

优点是无需密钥/匿名会话初始化、响应体短，三个重点基金都取得有效报价；局限是当前单代码接口、跨境时效差，只有收盘后这段连续复读证据。站点说明其模型根据季报披露数据计算，**平台估值不是本项目自己推算，也不是基金官方 NAV**。[医药估值页与模型说明](https://fund.dayfund.com.cn/fundpre/015916.html)。

### Fund123：可读分时序列，但应保留实验状态

正常匿名流程为访问[基金档案页](https://www.fund123.cn/matiaria?fundCode=015916)，取得页面本身下发的产品 ID/CSRF，再按其[客户端脚本](https://gw.alipayobjects.com/a/finfundpcbff/fundMatiaria-4d369de21fef60c73b5b.js)调用 `POST /api/fund/queryFundEstimateIntraday`。没有绕登录、签名或付费限制。

- 字段 `forecastNetValue` 为估算单位价格，`forecastGrowth` 是**小数收益率，要乘 100 才是 %**，`time` 是毫秒时间戳，须转上海时区。
- 最新点按真实时间选择，不假设列表顺序或请求 `limit=200` 就必定只有 200 条；本轮实际有 242 个点。
- 6 个匿名档案均带有 `isEstimateDowngrade=true`、页面文本“暂不提供”，但客户端正常取数路径仍实际返回国内四只分时数据；这说明**有可读能力，也有明显的接口变更风险**。
- 本轮恒生科技、标普500返回空序列；不能因 HTTP 200 / success=true 就计为估值成功。

两家候选的脚本 URL/hash、真实报价、时刻与缺项均在原始 JSON。**公开可读不代表已确认机器再分发授权或长期服务承诺**；两者底层模型/数据供应链与现有源是否独立，也未得到充分证明。

## 五、采样时的候选决策表（历史）

| 选择 | 收益 | 代价/未决问题 |
|---|---|---|
| 维持天天 → 新浪 | 保留用户已选规则，新浪能补主动基金及较广样本；生产改动为零 | 首段多一次批量请求，天天长时间陈旧时应按时效切换而非只看请求失败 |
| Dayfund 第三备用 | 对新浪整体失败或部分缺项提供额外参考，接入较轻 | 只能对确实新鲜的代码采用；港股/海外缺口、权限与盘中稳定性待验 |
| Fund123 实验/手动备用 | 国内主动基金的分时序列可用于复核、统计研究 | 产品映射/匿名会话、初始化成本、降级标记及跨境缺项，不宜直接依赖为唯一主源 |
| 直接把新浪设为主源 | 按本轮覆盖和延迟可少一次首段请求 | 尚无准确度/长期稳定性优势证据；**须用户决定，不在本次改动** |

**下一步最有价值的不是重写应用，而是市场时段感知和误差留证。** 所有平台估值都保留来源/时刻/基准 NAV 日；对还在交易的市场严格判断报价年龄，不能用上海收盘钳制放行很旧的海外报价。在相应正式 NAV 公布后再对齐日期计算误差；不同模型、时刻的盘中差值不能直接当成某家不准确的证据。

长期稳定性宜另在至少 3–5 个完整交易日、开盘/午休/收盘及国内外时段进行低频采样，统计失败、超时、新鲜度与覆盖分位数。**本次未创建定时任务或自动采购服务**，持续监测范围由用户另行确认。
