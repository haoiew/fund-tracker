## 安卓部署执行计划

### 前置准备

1. 确认后端服务部署地址（公网IP或域名）
2. 修改前端 API 请求地址指向实际后端服务
3. 安装 HBuilderX 开发工具

### 部署步骤

1. 使用 HBuilderX 打开 `fund-tracker/frontend` 项目
2. 配置 `manifest.json` 中的应用信息
3. 执行 发行 → 原生App-云打包 → Android
4. 下载生成的 APK 文件并安装测试

### 需要确认的问题

* 后端服务是否已部署到公网可访问的服务器？我需要你推荐个人可免费创建或者试用的服务器

* 是否需要自定义安卓证书？

* 是否需要配置应用图标和启动图？

请确认后，我将协助您完成具体的部署配置修改。
