## 问题分析

从截图看，首页实时估值模块只显示5只基金（012349, 017436, 016531, 018125, 015916），这是**旧的默认基金列表**。

### 根本原因

1. **前端 localStorage 缓存了旧的基金列表**
   - `dataManager.ts` 在初始化时会从 localStorage 恢复基金列表
   - 如果 localStorage 中有 `fund_tracker_fund_list`，就会使用缓存的5只基金

2. **加载顺序问题**
   ```
   1. 页面加载 → 从 localStorage 读取缓存（5只旧基金）
   2. 显示数据 → 只显示这5只
   3. 后台刷新 → 从API获取新列表（21只），但页面已渲染
   ```

3. **缺少 resetToDefault 方法**
   - `HomeView.vue` 第467行调用 `fundStore.resetToDefault()`
   - 但 `fundStore` 中没有这个方法
   - 点击"加载默认基金"按钮无效

### 解决方案

需要在 `fundStore` 中添加 `resetToDefault` 方法，该方法会：
1. 强制从API获取最新的默认基金列表
2. 更新 localStorage
3. 重新加载实时数据

### 实施步骤

1. 在 `fundStore.ts` 中添加 `resetToDefault` 方法
2. 在 `dataManager.ts` 中添加 `resetFundList` 方法
3. 清空 localStorage 中的 fund_list
