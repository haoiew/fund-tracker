## 问题分析

从日志和用户反馈发现了以下问题：

### 1. Portfolio服务报错
```
TypeError: can't multiply sequence by non-int of type 'decimal.Decimal'
```
`portfolio.hold_shares` 是字符串类型，无法与Decimal相乘。

### 2. 缓存问题

- 首页数据加载慢

### 3. OCR识别失败
- 需要查看OCR具体日志

- 需要查看具体错误

### 5. 弹窗数据显示问题
- 昨日净值、累计净值、日增长率为空

## 修复方案

hold_shares = float(portfolio.hold_shares) if isinstance(portfolio.hold_shares, str) else portfolio.hold_shares
