## 问题分析与修复计划

根据您的截图和参考代码 `fund_main.py` 的分析，我发现了以下核心问题：

***

### 问题1：统计数据和列表数据不一致

**根本原因：**

1. **两套计算逻辑**：
   - 统计卡片使用 `calculate_portfolio_profit()` 计算
   - 列表数据使用 `to_response()` 计算
   - 两者逻辑不一致，导致数据不匹配

2. **实时数据获取失败**：
   - `fund_service.get_realtime_data()` 可能返回 `estimate_nav` 为 null
   - `to_response()` 中当 `estimate_nav` 为 null 时，所有计算字段都为 null
   - 但 `calculate_portfolio_profit()` 使用了 `p.cost_amount` 作为 fallback

3. **数据库存储问题**：
   - 从截图看，基金 015916 的 `hold_shares` 显示为 0
   - 这意味着数据库中存储的数据本身不正确

***

### 问题2：当前净值、市值、盈亏等字段为空

**根本原因：**

`to_response()` 方法中的计算逻辑：
```python
if estimate_nav_float is not None and hold_shares > 0:
    current_value = hold_shares * estimate_nav_float
    profit_amount = current_value - cost_amount
    profit_rate = (profit_amount / cost_amount * 100) if cost_amount > 0 else None
```

如果 `estimate_nav_float` 为 null 或 `hold_shares` 为 0，所有字段都保持为 None

***

### 问题3：操作按钮不显示

**根本原因：**
- 表格列太窄，按钮被挤出可视区域
- `fixed="right"` 导致列被隐藏

***

## 参考代码 `fund_main.py` 的优秀实践

   - 优先级1: 天天基金实时估值
