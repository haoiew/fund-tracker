### 3. 后端窗口 (关键错误)
```
FundTracker-Backend-Python was not found; 
run without arguments to install from the Microsoft Store, 
or disable this shortcut from Settings > Manage App Execution Aliases.
```

**根本原因**：
- Windows将 `python` 命令指向了Microsoft Store的Python安装器
- 而不是系统中已安装的Python或conda环境
- 这是Windows的"App Execution Alias"功能导致的

### 解决方案

1. **禁用Windows App Execution Alias**
   - 进入设置 → 应用 → 高级应用设置 → 应用执行别名
   - 禁用python和python3的别名

2. **修改批处理文件**
   - 使用完整路径调用Python
   - 或者使用 `py` 命令
   - 或者正确初始化conda

3. **确保使用正确的Python**
   - 使用conda环境的完整路径
   - 或者使用 `python.exe` 的绝对路径
