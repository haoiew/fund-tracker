## 问题分析

### 错误日志
1. `timeout of 30000ms exceeded` - 请求超时
2. `Request failed with status code 405` - 方法不允许

### 根本原因
1. **Vite 代理配置不完整** - 缺少对 POST 请求的正确处理
2. **代理 rewrite 可能有问题** - `/api/funds/realtime/batch` → `/api/v1/funds/realtime/batch`

### 解决方案

#### 方案1：修复 Vite 代理配置
添加 `configure` 选项确保代理正确处理所有 HTTP 方法：
```javascript
proxy: {
  '/api': {
    target: 'http://localhost:8001',
    changeOrigin: true,
    rewrite: (path) => path.replace(/^\/api/, '/api/v1'),
    configure: (proxy, options) => {
      proxy.on('error', (err, req, res) => {
        console.log('proxy error', err);
      });
    }
  }
}
```

#### 方案2：简化请求路径
直接将 baseURL 设置为完整后端地址，不使用代理：
```typescript
const BASE_URL = 'http://localhost:8001/api/v1'
```

但这样会有跨域问题。

#### 方案3：后端添加 CORS 支持（已存在）
后端已有 CORS 配置，可以直接访问。

## 推荐方案

**修复 Vite 代理配置**，确保 POST 请求能正确转发到后端。

2. **重启前端服务** - 使配置生效
3. **测试 API 请求** - 验证修复结果
