## 📋 详细实施计划

### 阶段一：技术架构升级

**1. 迁移到 Vue 3 + TypeScript + Vite**
- 使用最新的 Vue 3.4+ 组合式API
- 引入 TypeScript 提供类型安全
- 使用 Vite 5.x 构建工具

**2. UI框架选择**
- 使用 **Element Plus** 或 **Naive UI** - 成熟的PC端组件库
- 配合 **Tailwind CSS** - 原子化CSS，快速定制样式
- 使用 **ECharts 5** - 专业图表库

**3. 状态管理**
- 使用 Pinia 替代 Vuex
- 模块化状态管理

---

### 阶段二：功能开发

**1. 基金筛选功能**
- 连续上涨/下跌筛选页面
- 可配置筛选条件（天数、幅度）
- 筛选结果列表展示

**2. 图表可视化**
- 基金净值走势图
- 支持多种时间范围（1W/1M/3M/6M/1Y/ALL）
- 多基金对比图表
- 收益率曲线

**3. 基金对比功能**
- 选择多只基金进行对比
- 对比表格展示
- 对比图表展示

**4. OCR识别功能**
- 拖拽上传截图
- 识别基金代码
- 自动添加到关注列表

### 阶段四：Electron打包

**技术方案：**
- 使用 **Electron** 打包为桌面应用
- 使用 **electron-builder** 生成安装包
- 支持 Windows/macOS/Linux
- 自动更新功能

**打包输出：**
- `.exe` - Windows安装包
- `.msi` - Windows企业部署包
- `.dmg` - macOS安装包
- `.AppImage` - Linux免安装包
