## 问题分析

### 问题1：编辑持仓时成本价未更新
在 `portfolioStore.ts` 的 `updateItem` 方法中，调用 `portfolioApi.update()` 时**漏传了 `cost_nav`**：

```javascript
// 当前代码（第176-180行）
portfolioApi.update(id, {
  hold_shares: data.hold_shares,
  cost_amount: data.cost_amount,
  buy_date: data.buy_date,
  remark: data.remark
  // ❌ 缺少 cost_nav
})
```

### 问题2：更新后数据未正确同步
虽然乐观更新了本地状态，但API返回后调用了 `dataManager.refreshPortfolio()`，这会从服务器重新获取数据，如果服务器数据不正确，会覆盖本地更新。

## 修复方案

### 1. 修复 `updateItem` 方法
添加 `cost_nav` 到API请求参数中。

### 2. 优化更新逻辑
确保更新后立即显示最新数据，不受后续刷新影响。
