## 二、技术选型理由

### 前端：UniApp + Vue3 + TypeScript
| 特性 | 说明 |
|------|------|
| **跨端能力** | 一套代码编译到微信小程序、H5、Android/iOS App |
| **开发效率** | Vue3 + Composition API，开发体验好 |
| **生态丰富** | 大量UI组件库(uView、uni-ui)，图表库(uCharts) |
| **性能优秀** | 原生渲染，接近原生App体验 |
| **Windows支持** | 可结合 Electron 或 Tauri 打包桌面端 |

### 后端：Python FastAPI
| 特性 | 说明 |
|------|------|
| **性能** | 基于Starlette，异步高性能 |
| **开发效率** | 自动API文档，类型提示支持 |
| **生态兼容** | 复用现有akshare等Python金融库 |
| **AI集成** | 方便集成OCR、NLP等AI能力 |

### 数据库：PostgreSQL + Redis
| 组件 | 用途 |
|------|------|
| PostgreSQL | 主数据库，存储用户、持仓、基金历史数据 |
| Redis | 缓存热点数据(实时估值)、会话管理 |

## 五、数据库Schema设计

```sql
-- 基金基础信息表
CREATE TABLE funds (
    id SERIAL PRIMARY KEY,
    code VARCHAR(10) UNIQUE NOT NULL,      -- 基金代码
    name VARCHAR(100) NOT NULL,             -- 基金名称
    type VARCHAR(20),                       -- 基金类型
    company VARCHAR(100),                   -- 基金公司
    created_at TIMESTAMP DEFAULT NOW()
);

-- 基金历史净值表
CREATE TABLE fund_nav_history (
    id SERIAL PRIMARY KEY,
    fund_code VARCHAR(10) REFERENCES funds(code),
    nav_date DATE NOT NULL,                 -- 净值日期
    nav DECIMAL(10,4),                      -- 单位净值
    accum_nav DECIMAL(10,4),                -- 累计净值
    daily_change DECIMAL(6,2),              -- 日涨跌幅
    UNIQUE(fund_code, nav_date)
);

-- 用户表
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    openid VARCHAR(50) UNIQUE,              -- 微信openid
    username VARCHAR(50),
    avatar_url TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 用户持仓表
CREATE TABLE user_portfolio (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    fund_code VARCHAR(10) REFERENCES funds(code),
    hold_shares DECIMAL(12,4),              -- 持有份额
    cost_amount DECIMAL(12,2),              -- 投入金额
    cost_nav DECIMAL(10,4),                 -- 成本净值
    buy_date DATE,                          -- 购买日期
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 实时估值缓存表
CREATE TABLE fund_realtime_cache (
    fund_code VARCHAR(10) PRIMARY KEY,
    estimate_nav DECIMAL(10,4),             -- 估算净值
    estimate_change DECIMAL(6,2),           -- 估算涨跌幅
    update_time TIMESTAMP,
    cached_at TIMESTAMP DEFAULT NOW()
);
```

## 六、API接口设计

### 基金相关
```
GET    /api/v1/funds                    # 获取基金列表
GET    /api/v1/funds/{code}             # 获取基金详情
GET    /api/v1/funds/{code}/realtime    # 获取实时估值
GET    /api/v1/funds/{code}/history     # 获取历史净值
POST   /api/v1/funds/search             # 搜索基金
```

### 持仓相关
```
GET    /api/v1/portfolio                 # 获取用户持仓
POST   /api/v1/portfolio                 # 添加持仓
PUT    /api/v1/portfolio/{id}            # 更新持仓
DELETE /api/v1/portfolio/{id}            # 删除持仓
GET    /api/v1/portfolio/summary         # 获取持仓汇总
GET    /api/v1/portfolio/profit          # 获取收益统计
```

### OCR相关
```
POST   /api/v1/ocr/scan                  # 上传截图识别
```
