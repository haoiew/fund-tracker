# 统一配置模块重构方案

## 目标
创建一个统一的配置管理系统，解决 fund_core.py 和 fund-tracker/backend/app/config.py 之间的配置重复问题，支持跨项目共享配置。

## 设计方案

### 1. 创建共享配置模块
**位置**: `shared/config.py`

**结构**:
```python
# 基础配置类
class BaseConfig:
    # 应用信息
    APP_NAME: str = "基金跟踪器"
    APP_VERSION: str = "2.0.0"
    
    # 环境检测
    DEBUG: bool = False
    ENV: str = "development"

# 基金数据配置
class FundConfig(BaseConfig):
    # 默认基金列表
    DEFAULT_FUNDS: List[str] = [...]
    
    # 筛选阈值
    SCREEN_UP: dict = {"days": 2, "pct": 0.03}
    SCREEN_DOWN: dict = {"days": 3, "pct": 0.03}
    
    # 数据源配置
    DATA_SOURCES: List[str] = [...]
    REQUEST_TIMEOUT: int = 5
    REQUEST_RETRY_TIMES: int = 3

# 图表配置
class ChartConfig(BaseConfig):
    # 时间范围
    TIME_RANGES: dict = {...}
    
    # 颜色配置
    COLORS: dict = {...}
    
    # 基准指数
    BENCHMARKS: dict = {...}

# 绘图配置（用于 fund_core.py）
class PlotConfig(BaseConfig):
    PLOT_MODE: int = 0
    PLOT_RANGE: str = "1W"
    SHOW_BENCHMARK: bool = True
    SHOW_NAME_LOADING: bool = False
```

### 2. 环境变量支持

#### 3.3 更新前端配置
- 统一环境变量命名规范
