# 前端预览方案

## 当前问题
前端是 UniApp 项目，需要特定的构建工具才能运行。目前无法直接预览，因为：
1. 依赖未安装（node_modules 不存在）
2. 需要 UniApp CLI 或 HBuilderX 构建

## 解决方案

### 方案1: 安装依赖并启动 H5 开发服务器（推荐）
```bash
cd fund-tracker/frontend
npm install
npm run dev:h5
```
然后访问 http://localhost:3000 或控制台输出的地址

### 方案2: 使用 HBuilderX（官方推荐）
1. 下载 HBuilderX: https://www.dcloud.io/hbuilderx.html
2. 打开 fund-tracker/frontend 项目
3. 点击运行 → 运行到浏览器

### 方案3: 使用 VS Code + 插件
安装 UniApp 插件后可直接运行

### 方案4: 构建静态页面
```bash
cd fund-tracker/frontend
npm install
npm run build:h5
# 生成 dist/build/h5 目录，可用任意服务器托管
```

## 建议
先执行方案1，如果 npm install 失败再考虑方案2使用 HBuilderX
