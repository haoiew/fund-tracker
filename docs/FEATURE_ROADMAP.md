# 基金跟踪器功能路线图

> 基于多数据源能力的新功能开发计划
> 版本: v2.1.0 - v3.0.0
> 更新时间: 2026-02-06

---

## 概述

随着多数据源架构的完善，我们可以开发一系列基于数据智能分析的新功能。本路线图规划了未来4-5个迭代周期的功能开发计划。

---

## 功能分类总览

| 类别 | 功能数量 | 优先级 | 预计周期 |
|------|----------|--------|----------|
| 数据智能分析 | 3个 | P0-P1 | 1-2周 |
| 投资分析 | 4个 | P1-P2 | 2-3周 |

## 第一阶段：数据基础增强（1-2周）

### 1. 数据源健康度监控面板 ⭐ P0
**功能描述**: 实时监控各数据源的可用性、响应时间、成功率

**用户价值**:
- 了解当前数据质量
- 知道哪些数据源在工作
- 增强对系统的信任

**核心功能**:
- [ ] 数据源状态仪表盘
- [ ] 实时响应时间图表
- [ ] 成功率统计
- [ ] 自动切换告警
- [ ] 历史可用性趋势

**技术要点**:
```python
# 后端：记录每个数据源的请求统计
class DataSourceMetrics:
    source_type: str
    total_requests: int
    success_count: int
    fail_count: int
    avg_response_time: float
    last_success_time: datetime
    last_fail_time: datetime
```

**API设计**:
```
GET /api/v1/datasource/metrics
GET /api/v1/datasource/{source}/history
```

### 3. 基金价格预警 ⭐ P1
**功能描述**: 设置价格/涨跌幅预警，触发通知

**用户价值**:
- 及时把握买卖时机
- 无需持续盯盘
- 自动化监控

**核心功能**:
- [ ] 多条件预警设置（价格、涨跌幅、净值）
- [ ] 系统托盘通知
- [ ] 声音提醒
- [ ] 预警历史记录
- [ ] 批量预警管理

**预警条件类型**:
1. 价格达到设定值
2. 涨跌幅超过阈值
3. 估值分位数突破
4. 连续涨跌天数

---

### 4. 基金数据质量评分 ⭐ P1
**功能描述**: 基于多数据源对比，给基金数据质量打分

**用户价值**:
- 了解数据可信度
- 辅助投资决策
- 发现数据问题

**评分维度**:
- [ ] 多源一致性（40%）
- [ ] 数据新鲜度（30%）
- [ ] 历史准确率（30%）

**评分等级**:
- A级（90-100）：数据优秀，高度可信
- B级（75-89）：数据良好，基本可信
- C级（60-74）：数据一般，谨慎参考
- D级（<60）：数据较差，建议核实

**指数计算**:
```python
# 恐慌/贪婪指数 (0-100)
# 基于：涨跌比、涨跌幅分布、成交量等
sentiment = (
    up_ratio * 0.3 +
    avg_change_score * 0.3 +
    volume_score * 0.2 +
    volatility_score * 0.2
) * 100
```

    fund_code VARCHAR(10),
    user_id INTEGER,
    content TEXT,

    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

CREATE TABLE data_source_metrics (
    id INTEGER PRIMARY KEY,
    source_type VARCHAR(50),
    metric_date DATE,

);

    id INTEGER PRIMARY KEY,

## 风险评估
